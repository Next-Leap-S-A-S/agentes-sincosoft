# Agentes de IA, Operaciones Sincosoft

**Publicado en:** https://next-leap-s-a-s.github.io/agentes-sincosoft/

Página hermana de `~/Downloads/sincosoft-prompts-rci.html` (Prompts RCI de Sincosoft), con el formato «la receta» de `asistentes-ia-sabana`.

Seis secciones: Concepto (prompt, agente con aprobación, agente autónomo, con test), Ingredientes (siete), Receta (ocho agentes, dos por área: proyectos, contable, talento humano, comercial), Plataformas, Tu mapa (entregable del módulo 5: tres tareas con su flujo, se guarda en el navegador) y Antes de servir.

Se edita en `src/` (`template.html`, `agentes.js`) y se genera con `python3 src/build.py`, que revisa extensión y reglas de redacción y escribe `index.html` como un único archivo.
